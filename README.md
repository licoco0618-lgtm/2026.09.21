# 智光商工 115學年度 新生（一年級）繡學號作業系統

本系統依據學校發布之三份正式 PDF 規範檔案（01 日程表、02 流程圖解、03 收費明細表）進行數位化建置，提供導師、班長、總務股長與同學一站式的送繡管理與收費計算工具。

## 🌟 核心功能特色

### 1. 📋 03 各班收費明細表（31人完整名冊）
- **預設班級**：資處一仁（亦可於介面自訂修改）。
- **完整 31 人編制**：預設建置座號 1 ~ 31 位學生名冊，無須逐一手動增減。
- **📱 點名字再選衣服（一排 6 人精緻網格）**：
  - **👤 第一步・點選同學名單**：所有 31 位同學以 **一排 6 個** 緊湊卡片呈現，全班名單一目了然無需滑動，顯示座號、姓名與收費狀態。
  - **👕 第二步・專屬衣服送繡抽屜**：點擊任意同學即展開專屬彈出抽屜，包含姓名/學號即時修改、一鍵全套 7 件 ($395)、7 項衣服品項大觸控步進器（44px防誤觸）、上一位/下一位快速連跳切換。
- **📊 解決「同步到 Excel 字沒有正確／亂碼」的三大保證方案**：
  1. **📊 下載 Excel 檔 (.xls) [⭐ 最推薦]**：原生 Excel 格式，Windows 電腦直接雙擊開啟，**繁體中文微軟正黑體 100% 正確絕對不亂碼**，自帶官方表頭、框線與合計金額格式！
  2. **📋 一鍵複製至 Excel 剪貼簿 (按 Ctrl+V 貼上)**：點擊後切換到 Excel 任意空白處按 `Ctrl + V`，所有學生、學號與金額自動填入各儲存格，零難度！
  3. **📥 匯出相容 CSV 檔 (.csv)**：已加入微軟專用 UTF-8 BOM (`\uFEFF`)，防止 Excel 預設以 ANSI 開啟造成亂碼。
  4. **📤 智慧名單匯入**：自動辨識 **UTF-8** 與 Windows Excel 儲存常用的 **Big5 / CP950** 編碼，無論從何處匯入名冊，學生姓名與學號 100% 正確還原！
- **🔍 即時搜尋與催繳篩選**：支援即時輸入座號、姓名或學號快搜，並提供「全部 (31人) / ⚠️ 僅未繳費 / ✅ 僅已繳費」標籤，催繳對帳秒查。
- **A4 完美列印**：完全遵照官方 PDF 03 格式排版，包含班長簽章、總務股長簽章、導師簽章與班級資訊，點擊「列印收費表」即可直接輸出紙本或存為 PDF。
- **資料自動保存**：輸入之姓名、學號與件數均自動儲存於本機瀏覽器，重新整理或關閉視窗不遺失。

### 2. 🗓️ 01 繡學號日程表
- **完整呈現關鍵日程**：
  - **9/22 (二)**：便服收繳時間。
  - **9/23 (三)**：補行送繡最後一日。
  - **9/24 (四)**：廠商預計送回學校／新生體檢日。
  - **12/1 (二)**：建教班一信乙特別協調。
- **便服規定防呆提醒**：註明便服日不得穿著裙子、短褲、薄紗、破衣褲，以及體檢日便服輕便穿脫原則。
- **教官室諮詢窗口**：生輔組長 蘇教官 (02-29411831 或 02-29432491 轉 510)。

### 3. 📌 02 送繡標準作業流程 (SOP)
- **圖解 5 大步驟**：領取物料 → 貼 A 貼紙核對學號 → 裝 B 袋貼 C 貼紙 → 總務股長對點收費 → 裝 D 班級麻布袋校門對點交件。
- **四大物料說明**：A (12小張)、B (個人袋)、C (袋標)、D (班級麻布袋)。

### 4. 💵 總務現金對帳計算機
- 總務股長收齊現金後，輸入 1000、500、100、50、10、5、1 元之張數或枚數，系統立即核對實收與應收總額是否相符。
